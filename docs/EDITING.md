# Editing the portfolio

- Update copy, skills, learning topics, project links, and image paths in `public/assets/js/content.js`.
- Place screenshots and the portrait in `public/assets/images/`.
- The favicon is `public/assets/icons/favicon.svg`.
- Styles are in `public/assets/css/`; their load order in `public/index.html` preserves the approved design. Do not alphabetize the stylesheet links.
- Scripts are deferred and depend on the order in `public/index.html`.
- The intro runs on fresh loads. Reduced-motion preferences skip it, while Pause atmosphere stops decorative loops.
- Sound is muted by default and is activated only by the visitor.
- Contact uses a mailto link. There is no contact database, upload endpoint, or analytics service.

Before pushing, run the checks listed in the root README and preview desktop and mobile layouts.
